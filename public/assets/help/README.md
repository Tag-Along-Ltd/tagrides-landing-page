# User-help image assets

The `review-2026-09/` images are actual Flutter UI rendered from the source
worktree with deterministic fictional data. They are not live customer accounts,
real financial records or proof of connected-service acceptance.

Capture entrypoint and automation: sibling `tagrides-frontend/tools/help_capture/`.
Captions, callouts, source commit and crop metadata: `src/data/help/screenshots.mjs`.
Only visually reviewed captures are prepared here. Temporary PNGs and debug
reports live outside the repositories and are removed after review.
