## Documentation workflow findings (not app defects)

- Fixed the fixture's history envelope to include journey/session timestamps so
  the real parser can construct the record. The history screenshot now shows a
  real rendered sample journey rather than a malformed-fixture error.
- Fixed wallet fixture fields to use the actual kobo wire contract. Sample fare,
  fee and driver earning are ₦500, ₦75 and ₦425; no payment was executed.
- Real-time panels are rendered from controlled production view models and clearly
  labelled sample data. The pending driver-location message in pickup examples
  is retained, not hidden as if a live GPS run had passed.

Publication gate: each guide's controls match the selected build; screenshots
are actual UI, privacy-checked and platform-labelled; there are no invented
success states, payment promises or generic stand-in screenshots. Any remaining
unreachable state stays explicitly pending in the manifest.
